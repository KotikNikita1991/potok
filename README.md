# Поток

Планировщик работы для одного человека. Задачи идут одной линией, как поток работ в календарно-сетевом графике: занимают только рабочее время, обходят обед и выходные, а при вставке новой задачи остальные сдвигаются вправо. По каждой задаче сразу видно, когда она закончится.

## Как это работает

- **Живой план.** Следующая задача начинается, когда реально закончилась предыдущая. Закрыли раньше, и всё подтянулось влево. Не закрыли к сроку, и задача растягивается, а остальные едут вправо.
- **Запас.** Задачу можно потянуть вправо: перед ней появится запас, который едет вместе с ней. Новая задача, поставленная перед ней, сначала расходует запас.
- **Прерывание.** Срочная задача может начаться прямо сейчас. Текущая режется, её остаток уходит после новой.
- **Точное время.** Созвон закрепляется на дату и время, остальные задачи обходят его, как обед.
- **Календарь.** Обычная неделя настраивается в настройках, любой день отдельно, нажатием на его заголовок на графике. Праздники РФ учитываются и отключаются одной настройкой.
- **Синхронизация.** Данные лежат в секретном Gist на GitHub, между устройствами сливаются по времени изменения. Без сети всё работает и отправляется позже.

## Google Таблица

«Поток» обменивается задачами с Google Таблицей, где список задач месяца ведётся построчно: «Дата», «Задача» (в этом столбце статус), «Описание», «Нагрузка», «SP», «Часы», «Минуты», «Ссылка». Столбцы находятся по названиям в шапке, поэтому их порядок не важен.

- **Из таблицы в «Поток».** Новые строки листа становятся задачами. Готовые по умолчанию не загружаются. Те, что ждут кого-то другого («на переводе», «нужна инфа»), попадают в «Без даты» с пометкой. Остальные встают в очередь. Время берётся из «Часов» и «Минут», а если они пустые, оценивается по нагрузке.
- **Из «Потока» в таблицу.** Задачи месяца, которых ещё нет в листе, дописываются под последней строкой. В уже связанных строках обновляется статус. Нагрузка ставится по оценке времени, её можно поправить перед выгрузкой.
- **SP остаются за таблицей.** Столбцы SP, «Часы» и «Минуты» «Поток» не заполняет: их считает генератор SP в самой таблице. 1 SP равен 15 минутам.
- **Без дублей.** Строка и задача узнают друг друга по тексту описания и по номеру вида `[ABC-123]`, поэтому лист можно сортировать и править. Перед загрузкой и перед выгрузкой показан список того, что изменится.

Подключение: значок таблицы в верхней панели. Там пошаговая инструкция и кнопка, которая копирует код скрипта [apps-script/potok.gs](apps-script/potok.gs). Скрипт ставится в саму таблицу и разворачивается как веб-приложение. Его адрес хранится вместе с данными «Потока» и приходит на второе устройство через синхронизацию.

## Жесты

| Действие | Компьютер | iPhone |
| --- | --- | --- |
| Открыть задачу | клик | касание |
| Отложить старт | потянуть влево или вправо | долгое нажатие и потянуть |
| Поменять порядок | вытащить вверх или вниз из линии | то же после долгого нажатия |
| Изменить длительность | потянуть за правый край | то же после долгого нажатия |
| Вставить задачу | «+» под линией или клик по пустому месту | «+» под линией |
| Настроить день | клик по заголовку дня | касание заголовка |
| Масштаб | Ctrl + колесо, кнопки «−» и «+» | щипок, кнопки «−» и «+» |

Клавиши на компьютере: `N` новая задача, `T` к текущему моменту, `/` поиск, `Ctrl+Z` отмена, `Ctrl+Enter` сохранить, `Esc` закрыть.

## Разработка

Сборки нет, только статические файлы и ES-модули, зависимостей тоже нет.

```bash
npm test
```

```bash
npm run serve
```

Обмен с таблицей можно проверить без настоящей таблицы. Команда ниже запускает учебную таблицу с придуманными задачами, её адрес для подключения в приложении: `http://localhost:5178/exec`.

```bash
npm run mock-table
```

Для проверки логики времени можно открыть страницу с параметром `?now=2026-11-02T10:40`. Перед публикацией нужно обновить версию кэша:

```bash
npm run stamp
```

Шрифт Onest распространяется по лицензии SIL Open Font License, текст в `assets/fonts/OFL.txt`.
